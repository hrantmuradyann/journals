# News Digest

**First time only** (installs Flask):

    pip3 install -r requirements.txt

**Every time:**

1. In Terminal, inside this folder:

       python3 app.py

2. Open http://127.0.0.1:5000 in your browser.
3. Click **Check latest news** — wait a minute, then browse the tabs.

To stop the server press `Ctrl+C` in Terminal.

To change which words go to which tab, edit the lists at the top of `classify.py`.
